# Account Palette System

Use this when building or redesigning TikTok Shop / social-commerce slideshows for this user.

## Core lesson from reference batch

The user likes creator accounts that have a recognizable repeated color system, but does **not** want the default account identity to lean too beauty/feminine. Violet, berry, burgundy, and plum work for skincare/hair/lash/women-focused products, but should not be the account-wide default.

## Default universal palette

Use a warm, natural, home-friendly palette that works across books, home, kitchen, kids/family, pets, lifestyle, wellness, and occasional gender-targeted products.

## Typography color rule

Use two-color text hierarchy:

- normal words: deep espresso brown / soft charcoal
- emotional or key sales words: muted burnt terracotta / warm clay
- small captions: olive charcoal, warm brown, or soft charcoal

Examples:

```text
"your child’s bedtime" = deep espresso
"finally feels calm" = muted terracotta
```

```text
"nobody talks about" = soft charcoal
"this kitchen problem" = muted terracotta
```

## Background rule

For realistic/photo slides, do not force flat beige backgrounds. Use real home backgrounds that naturally contain the palette: cream walls, beige bedding, light oak tables, muted sage props, warm kitchen counters, linen textures, warm white bathroom tiles.

For graphic/animated slides, flat warm cream/oat beige/soft greige/muted sage backgrounds are fine. Use terracotta mainly as text emphasis, not as a default full-slide background.

## Niche adjustment rule

Keep the same core palette but allow small shifts:

- books/kids/family: more warm cream, light oak, gentle sage, muted golden beige
- beauty/women: may add muted rose/plum, but do not replace the default identity unless requested
- men/gadgets/car/tools: lean more soft charcoal, stone, oak, muted sage, but keep terracotta as accent
- home/kitchen/pets: use the default directly
